# Student Mental Health Analysis — Work in Progress

**Status:** Work in progress.

This project explores a university student dataset with variables related to depression, social connectedness, acculturative stress, student type, language proficiency, academic level, and length of stay.

## Current state
The source notebook contains the project data and setup, but the final analysis query/workflow is not complete. It is included here transparently as a work-in-progress project rather than presented as finished work.

## Planned next steps
- Complete the final SQL/statistical analysis.
- Examine mental-health measures by length of stay and student type.
- Add reproducible summary tables and conclusions.
- Document limitations and interpretation.

## Public repository files
- `analysis.sql` — extracted analysis/source code from the original workbook
- `README.md` — project scope, methods, and highlights

> **Data note:** The original project used course-provided datasets in DataCamp/DataLab. Those raw datasets and reference images are intentionally not redistributed in this public repository. The source code keeps the original expected filenames for reproducibility with an authorized local copy of the data.
