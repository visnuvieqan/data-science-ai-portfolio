# NYC Public School SAT Performance Analysis

**Focus:** pandas analysis, ranking, grouped statistics, and variability analysis.

This project analyzes SAT performance across NYC public schools.

## Work performed
- Filtered schools against a math-performance benchmark.
- Created a combined SAT score from math, reading, and writing.
- Ranked schools by performance.
- Aggregated results by borough and compared variability.

## Highlight
The analysis identified **Stuyvesant High School** as the top combined SAT performer in the supplied dataset and found **Manhattan** had the greatest borough-level variation.

## Public repository files
- `analysis.py` — extracted analysis/source code from the original workbook
- `README.md` — project scope, methods, and highlights

> **Data note:** The original project used course-provided datasets in DataCamp/DataLab. Those raw datasets and reference images are intentionally not redistributed in this public repository. The source code keeps the original expected filenames for reproducibility with an authorized local copy of the data.
