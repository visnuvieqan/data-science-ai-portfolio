# Investigating Netflix Movies

**Focus:** Exploratory data analysis, filtering, and visualization.

This project explores Netflix movie data with a focus on films released during the 1990s.

## Work performed
- Loaded and analyzed a dataset of more than 4,800 Netflix titles.
- Filtered movies released between 1990 and 1999.
- Visualized movie-duration distributions with Matplotlib.
- Investigated short Action movies using multi-condition filtering.

## Highlight
The original project identified **7 Action movies under 90 minutes** in the 1990s subset.

## Public repository files
- `analysis.py` — extracted analysis/source code from the original workbook
- `README.md` — project scope, methods, and highlights

> **Data note:** The original project used course-provided datasets in DataCamp/DataLab. Those raw datasets and reference images are intentionally not redistributed in this public repository. The source code keeps the original expected filenames for reproducibility with an authorized local copy of the data.
