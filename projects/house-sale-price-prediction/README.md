# House Sale Price Prediction

**Focus:** Regression, data cleaning, feature preparation, and price prediction.

This project uses historical property-sale data to predict house sale prices.

## Work performed
- Cleaned and standardized missing, malformed, numerical, categorical, and date fields.
- Explored relationships between property characteristics and sale price.
- Prepared features with reusable scikit-learn preprocessing steps.
- Built Linear Regression and Random Forest regression models.
- Generated sale-price predictions for unseen validation properties.

## Portfolio extension
A later 5-fold validation of the supplied training data showed Random Forest outperforming Linear Regression, with approximately **0.98 R²** and **$10.8K MAE**.
