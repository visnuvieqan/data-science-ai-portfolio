# Hotel Operations & Service Performance Analysis

**Focus:** SQL cleaning, joins, aggregation, and operational performance analysis.

This project analyzes an international hotel operation with a customer-satisfaction target of 4.5.

## Work performed
- Cleaned invalid branch data using SQL expressions, casting, trimming, regex validation, and standardization.
- Corrected inconsistent categorical values.
- Joined branch, request, and service data.
- Calculated response-time and satisfaction metrics.
- Identified branch/service combinations performing below the target rating.

## Highlight
The reviewed analysis covered **100 hotel branches**, **385 branch/service response-time combinations**, and identified **215 branch/service combinations** below the 4.5 target.

## Public repository files
- `analysis.sql` — extracted analysis/source code from the original workbook
- `README.md` — project scope, methods, and highlights
